🚢 BayScope
BAPLIE Viewer & Manager

Created by Chief Mate Mamuka Nakashidze

BayScope Lite is a professional application that allows you to open and edit BAPLIE files and export the modified versions in the following formats:

EDI 1.5 / 2.0 / 2.2

The application allows you to filter containers according to various parameters, including:
- Loading and discharge ports;
- Empty and full containers;
- Container length, weight, and height;
- Container position and number;
- IMDG class;
- Reefer containers and their Set Points;
- And other important parameters.
This unique pocket-sized tool is designed to make your daily work significantly easier, both in port and beyond.

The application will be particularly useful not only for deck officers but also for electro-technical officers, as it enables them to quickly locate specific reefer containers and check their corresponding Set Points.

At this stage, BayScope Lite is available exclusively for Android devices.
